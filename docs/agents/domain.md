# Domain Docs

This is a single-context repository.

Before changing product behavior, read:

1. `CONTEXT.md` at the repository root;
2. relevant entries in `docs/decisions.md`;
3. relevant ADRs in `docs/adr/` when they exist.

Use the vocabulary defined in `CONTEXT.md`. If an implementation or proposal contradicts a recorded decision, make that conflict explicit instead of silently overriding it.
